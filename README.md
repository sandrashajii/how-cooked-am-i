## Project Description

**How Cooked Am I?** is an AI-powered web application that analyzes a user's situation and determines how "cooked" they are.

It generates a humorous cooked percentage, severity level, and sarcastic AI-generated verdict based on the situation provided by the user.

---

## The Problem (that doesn't exist)

People have problems every day, but there is no scientific way to measure exactly how badly they have messed up. 😭

---

## The Solution (that nobody asked for)

How Cooked Am I? uses AI to analyze the user's situation and calculate a Cooked Score, assign a severity level, and provide a brutally honest but funny verdict.

Because apparently, we needed science for bad decisions. 🔥

# Implementation

The application collects the user's situation through a text area.

JavaScript processes the input and sends it to the AI for analysis. The AI generates a cooked percentage, severity level, and humorous diagnosis.

The result is then displayed dynamically on the webpage.

### Main Flow

User Input  
↓  
JavaScript Processing  
↓  
AI Analysis  
↓  
Cooked Percentage  
↓  
Severity Level  
↓  
Humorous Verdict
